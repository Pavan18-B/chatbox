# Secure Chatbox

A real-time chat room app built with Node.js, Express, and Socket.IO.

## Features
- Room-based chat
- Password-protected rooms
- Admin private code for password changes
- Chat history and message cleanup

## Run locally

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

## GitHub deployment
This project is a Node.js app, so it is best deployed on a hosting service like Render, Railway, or Heroku rather than GitHub Pages.

## Example deployment command

```bash
npm install
npm start
```
